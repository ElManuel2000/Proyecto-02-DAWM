# Torneo de Interfacultades | GG SPOL · ESPOL

Sitio informativo para el torneo interfacultades organizado por GG SPOL. La página usa la estructura original de la plantilla **Multiverse** de HTML5 UP: galería adaptable, lightbox para las disciplinas y panel de información deslizante.

## Ejecutar localmente

Abre `index.html` en un navegador o inicia un servidor HTTP estático desde la carpeta raíz:

```powershell
python -m http.server 8000
```

Visita `http://localhost:8000`.

# Análisis 

Para el desarrollo de este proyecto se seleccionó el Torneo de Videojuegos Interfacultades del club GG SPOL de la Escuela Superior Politécnica del Litoral (ESPOL). Esta actividad destaca por su formato híbrido (presencial en el campus y virtual mediante streaming y salas en línea) y su alto poder de convocatoria, involucrando activamente a estudiantes de diversas carreras como competidores, al equipo directivo del club como organizadores y a la comunidad académica como espectadores. 

A partir del levantamiento de información y la entrevista realizada a los organizadores, se determinó que la actividad es altamente relevante para fomentar la integración social, el trabajo en equipo y la cultura tecnológica en la ESPOL. Sin embargo, se identificaron retos operativos importantes, tales como los cruces con la carga académica y la necesidad de optimizar la conectividad y difusión. Por ello, el análisis de este escenario justifica la creación de una plataforma digital centralizada que agilice la comunicación, el registro de participantes y el acceso a las transmisiones en vivo.

# Diseño 

Para el desarrollo de la landing page del torneo de videojuegos interfacultades del club GG SPOL, se evaluaron tres opciones gratuitas de HTML5 UP: Parallelism, Prologue y Multiverse. 

Se selecciona Multiverse porque su estructura en cuadrícula satisface de manera sobresaliente las necesidades visuales y técnicas de un evento de videojuegos. A diferencia de Parallelism y Prologue, ofrece el equilibrio perfecto entre una estética moderna de alto impacto para la comunidad gaming de la ESPOL y la flexibilidad funcional necesaria para organizar la información clave del torneo de GG SPOL de forma intuitiva. 

# Implementación 

Para llevar a cabo la primera versión funcional de la landing page del torneo de videojuegos del club GG SPOL, se ejecutó la adaptación técnica del sitio web: 

- **Personalización del Código Base:** Se modificó el archivo index.html de la plantilla Multiverse (HTML5 UP) para integrar la identidad visual y los contenidos informativos oficiales del torneo interfacultades de la ESPOL (edición 2026, desarrollada en la FIEC). 

- **Estructuración de Contenidos:** Se adaptaron las tarjetas y galerías de la interfaz para detallar las disciplinas oficiales en competencia (Super Smash Bros. Ultimate, VALORANT, League of Legends, Clash Royale, entre otras) y los canales de contacto institucional. 

- **Control de Versiones:** Se estructuró un repositorio en GitHub para gestionar de manera ordenada el código fuente (HTML, CSS y recursos visuales), aplicando buenas prácticas mediante commits periódicas y sincronización de ramas.
