# Torneo de Interfacultades | GG SPOL · ESPOL

Sitio informativo para el torneo interfacultades organizado por GG SPOL. La página usa la estructura original de la plantilla **Multiverse** de HTML5 UP: galería adaptable, lightbox para las disciplinas y panel de información deslizante.

## Ejecutar localmente

Abre `index.html` en un navegador o inicia un servidor HTTP estático desde la carpeta raíz:

```powershell
python -m http.server 8000
```

Visita `http://localhost:8000`.

## Información del torneo

- Periodo general informado para la edición 2026: del 11 de mayo al 27 de julio.
- Modalidad presencial, edificio 11D de FIEC, ESPOL.
- Disciplinas: Super Smash Bros. Ultimate, Clash Royale, Fortnite, Free Fire, League of Legends, Mario Kart 8 Deluxe, Marvel Rivals, Minecraft, Mortal Kombat X y VALORANT.
- Consultas de inscripción: Instagram [@gg_spol](https://www.instagram.com/gg_spol/).

Las fechas y horarios específicos por juego, reglas, disponibilidad de inscripción y enlaces de streaming deben confirmarse con la organización.
